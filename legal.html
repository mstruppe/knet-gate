The website and downloads

These pages are static files. Their code adds no analytics, tracking cookies, sign-up forms, or accounts. Viewing the download page does not upload research projects.

The pages are hosted by GitHub Pages, and app downloads are delivered through GitHub Releases. GitHub processes connection information, including IP addresses, to provide these services. Its handling of this information is described in the GitHub privacy statement.

For questions about this site or your personal information, use the contact address above. If you email the operator, your email address and message are used to respond to your enquiry.

Research Studio on your Mac

Research Studio 0.3.0 stores working projects on your Mac and saves portable project files to locations you choose. The app has no built-in analytics or automatic project upload to this website.

When you use the AI agent, your messages and the project context needed for the task are sent through Codex to OpenAI using your own account. This can include manuscript text, mathematical inputs and results, and source excerpts. OpenAI’s account terms and privacy settings apply to that service.

Portable project files can contain manuscript drafts, analyses, sources, and conversation history. Sharing a project file shares the information it contains. Account credentials are excluded from these files.

Preview release

The current Mac download is a development preview for installation testing. It is not signed with an Apple Developer ID or notarized. Its download page describes the supported Mac configuration, separate dependencies, and first-launch procedure.

Third-party software notices are included with the app. This notice does not change the licenses of those components.
